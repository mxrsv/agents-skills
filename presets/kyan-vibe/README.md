# Preset: `kyan-vibe`

Personal `CLAUDE.md` used for live vibe coding — Vietnamese tone, short answers, frontend gates, and hard workflow rules.

## Install

```bash
npx github:mxrsv/agents-skills install --preset kyan-vibe
```

Manual:

```bash
cp presets/kyan-vibe/CLAUDE.md ~/.claude/CLAUDE.md
```

## Pair with

- `rules/` — hard rules L1–L10 expect `rules/core/` (and friends)
- `templates/CLAUDE.template.md` — start from a neutral template instead of this preset

## Adapt

Change language, emoji policy, and conciseness to match your stream or team. Keep the hard-rules skeleton if you want the same safety rails.
